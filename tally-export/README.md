# WooCommerce Tally Excel Export — Portfolio Demo

A sanitized portfolio demonstration of a custom WooCommerce admin tool that exports order information into an Excel file formatted for Tally workflows.

## What this demo demonstrates

- WordPress/WooCommerce plugin development
- Custom WooCommerce order metabox
- Secure WordPress AJAX action with nonce and capability checks
- WooCommerce order data extraction
- GST/state-based voucher logic
- Excel/XLSX generation
- Custom admin-role capabilities
- Admin menu restrictions and order-manager workflow

## Demo scope

This is a portfolio demonstration. It contains no production credentials, API keys, customer database, or external service credentials.

## Important

This code is based on a real client-side implementation. Publish it publicly only if you have permission to disclose the implementation. Otherwise, use it only as a private GitHub repository or create an independent demo implementation with different business rules.
